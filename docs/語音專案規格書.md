# 語音專案規格書（voice-studio-project v1）

這份規格書給**以後設計程式（遊戲、教材、互動網頁）的人或 AI** 使用。
只要照這份規格產生一個「語音專案檔」（`.voiceproj.json`），就能匯入手機的「語音工作室」App，
在手機上離線產生全部語音，再把產出的檔案放回程式裡播放。

> 給 AI 的一句話：**「請依照 RFPSCode/voice-studio-app 的 docs/語音專案規格書.md，為這個程式產生語音專案檔 `<id>.voiceproj.json`，並讓程式用 game-voice-v1 格式（voice/all.txt + voice/map.txt）播放語音。」**

---

## 1. 整體流程

```
程式（電腦）                                   手機 App「語音工作室」
────────────────                              ─────────────────────────
① 程式產生 <id>.voiceproj.json   ──傳到手機──▶  ② 匯入專案
   （台詞、角色、音色、情緒指令）                 ③ 離線產生語音（Qwen3-TTS）
                                                  試聽、重錄、選版本、兒童音色後製
⑤ 程式讀 voice/all.txt + map.txt ◀──匯出──────  ④ 匯出 all.txt + map.txt
   依 key 播放每一句、對嘴型
```

- 傳到手機的方法：LINE／Google 雲端硬碟／USB／Email 都可以；或把檔案放在網路上，App 用「從網址匯入」（例如 GitHub 的 raw 連結）。
- 同一個專案（`id` 相同）再次匯入時，App 只會把**內容改過的句子**標成「需要重錄」，其他句子保留。

---

## 2. 檔案格式

- 編碼 UTF-8 的 JSON，副檔名 `.voiceproj.json`（App 也接受 `.json`）。
- 大小建議 2 MB 以內；句子數建議 2000 句以內。
- 未列在規格中的欄位會被保留但忽略，可以用來放程式自己的資料（建議以 `x_` 開頭）。

### 2.1 最上層欄位

|---|---|---|---|
| `format` | ✔ | 字串 | 固定 `"voice-studio-project"` |
| `version` | ✔ | 整數 | 固定 `1` |

| `title` | ✔ | 字串 | 顯示名稱，例如「校園安全時光機」 |
| `description` |  | 字串 | 說明 |
| `updated` |  | 字串 | 產生時間（ISO 8601） |
| `engine` |  | 物件 | 見 2.2 |
| `instruct` |  | 字串 | **全部句子共用**的說話指令，例如「用台灣口音的國語說話，咬字清楚自然」 |

### 2.2 `engine`

| 欄位 | 預設 | 說明 |
|---|---|---|
| `model` | `"qwen3-tts-customvoice"` | 目前只有這個（Qwen3-TTS 12Hz 1.7B CustomVoice）。App 讓使用者選「標準 Q8_0」或「快速 Q4_K_M」量化版本 |
| `language` | `"chinese"` | 小寫語言名稱：`chinese` `english` `japanese` `korean` `german` `french` `russian` `portuguese` `spanish` `italian` `auto` |
| `temperature` | `0.8` | 0–1.5，越高越有變化（也越容易出錯） |
| `topP` | 模型預設 | 0–1 |
| `seed` | `-1` | `-1`＝每個角色用自己的固定種子（見 2.3.2）；固定數字＝全部角色用同一個種子 |
| `taiwan` | `true` | 台灣讀音：常用詞自動改成台灣讀音（見 2.5） |
| `clean` | `true` | 乾淨語音：自動加上「不要喘氣、不要多餘的聲音、不要停頓太久」的指令，並在手機上去除喘氣、雜音和過長的停頓（見 2.7） |

### 2.3 `roles[]` 角色

| 欄位 | 必填 | 說明 |

| `id` | ✔ | 角色代號（英數、`_`、`-`），台詞用它指定角色，也會出現在 `key` 裡 |
| `name` | ✔ | 顯示名稱，例如「小凱(五年級)」 |
| `speaker` | ✔ | 內建音色，見下表 |
| `instruct` |  | 這個角色**固定的**說話方式（例如「說故事的語氣」），通常留空。**不要寫聲音高低粗細、年齡**（會讓每句聲音不同，請用 `post`），也不要寫情緒（情緒寫在每一句） |
| `post` |  | 後製（男童、女童、惡魔、天使…），見 2.3.1 |
| `seed` |  | 固定的隨機種子，見 2.3.2 |

#### 2.3.1 `post` 後製（在手機上做，不需要重錄）

**原則：每個角色固定一個 `speaker`（音色），角色感用後製做出來。** 不要用 `instruct` 描述聲音的高低、粗細、尖細（例如「聲音尖細」「低沉沙啞」），模型會因此每句換一種聲音；這些請交給後製。

| 欄位 | 預設 | 範圍 | 說明 |
|---|---|---|---|
| `enabled` | `false` | | 是否後製 |
| `preset` | `""` | 見下表 | 設定組名稱（只用來顯示；實際數值以其他欄位為準） |
| `pitchHz` | `0` | 0, 80–500 | 這個角色的目標音高（Hz）。`0`＝用這個角色自己的平均音高（不整體移動，只配合 `pitchLock` 讓每句一致） |
| `pitchLock` | `0.5` | 0–1 | 音高統一：`0`＝保留每句原本的高低，`1`＝每句都拉到目標音高。越大，同一個角色越一致。為了不傷害咬字，每句的音高調整限制在約 −6～+8 個半音內 |
| `formant` | `1.0` | 0.8–1.4 | 共振峰（聲道長短）。>1 像小孩、<1 像大塊頭；只調音高不調共振峰會像卡通鼠聲 |
| `speed` | `1.0` | 0.7–1.3 | 語速 |
| `octDown` | `0` | 0–1 | 低八度疊音（怪獸、惡魔感） |
| `octUp` | `0` | 0–1 | 高八度疊音（天使、精靈的光澤感） |
| `growl` | `0` | 0–1 | 沙啞、粗糙 |
| `bassDb` | `0` | −12–12 | 低音加強／減弱（dB） |
| `trebleDb` | `0` | −12–12 | 高音加強／減弱（dB） |
| `echoMs` | `0` | 0–800 | 回聲延遲（毫秒），`0`＝沒有回聲 |
| `echoFeedback` | `0.3` | 0–0.85 | 回聲次數（越大回聲越多次） |
| `echoMix` | `0` | 0–1 | 回聲音量 |
| `reverb` | `0` | 0–1 | 殘響（空間感） |

處理順序：音高／共振峰／語速／沙啞（同一次處理）→ 疊音 → 低音／高音 → 回聲 → 殘響 → 音量統一與防爆音。

後製的演算法（App 內建，產生端不用處理，只是讓設計時知道效果）：
- 音高、共振峰、語速、沙啞：TD-PSOLA（以聲帶脈衝為單位剪接），保留每個脈衝的原始波形，不會有 FFT 變調常見的金屬聲、水波聲；四個參數都是 1／0 時輸出和輸入完全相同。共振峰用帶限的 Kaiser sinc 讀取每個片段來調整。
- 沙啞（`growl`）：每隔一個脈衝變小聲，加上輕微的週期抖動，像真實的粗嗓子，不是失真。
- 疊音（`octDown`／`octUp`）：同一套 PSOLA 做出的低八度／高八度聲音，和原聲對齊。
- 回聲：每次重複越來越暗、越薄；人聲正在說話時回聲自動壓低（ducking），停頓時才出現，不會蓋住字。
- 殘響：8 路回授延遲網路（FDN），高頻消失得比低頻快、去掉低頻轟聲，人聲說話時同樣自動壓低。
- 最後把每一句的說話部分調到相同響度（約 −17 dBFS RMS），再用 3 毫秒前瞻限幅器防止爆音，並剪掉聽不到的尾巴。

**設定組（`preset`，App 與編輯器都有，選了之後還可以再微調）**

| 設定組 | 數值 | 建議音色 |
|---|---|---|
| 男童 | pitchHz 270、pitchLock 0.6、formant 1.17、trebleDb 1 | aiden |
| 女童 | pitchHz 300、pitchLock 0.6、formant 1.2、trebleDb 1 | vivian |
| 可愛女聲 | pitchHz 0、pitchLock 0.6、formant 1.1、speed 1.03、trebleDb 2 | vivian |
| 渾厚男聲 | pitchHz 0、pitchLock 0.6、formant 0.9、bassDb 4、trebleDb -1 | uncle_fu |
| 一般女聲 | pitchHz 0、pitchLock 0.6、formant 1.0 | serena |
| 一般男聲 | pitchHz 0、pitchLock 0.6、formant 1.0 | uncle_fu、ryan |
| 惡魔 | pitchHz 0、pitchLock 0.6、formant 0.9、octDown 0.2、growl 0.12、bassDb 2、echoMs 100、echoFeedback 0.25、echoMix 0.2 | ryan |
| 天使 | pitchHz 0、pitchLock 0.6、formant 1.08、octUp 0.18、trebleDb 3、reverb 0.35 | serena |
| 不處理 | enabled false | |
| 自訂 | 自己填各欄位 | |

不同角色共用同一個音色時，用不同的 `pitchHz`／`formant` 區分（例如兩個男童 240 Hz 與 290 Hz）。

#### 2.3.2 `seed`（選填）

每個角色的每一句，第一個版本都從同一個隨機種子開始產生，聲音會更一致。不填時由角色 `id` 自動決定；想換一種感覺可以填任意正整數。

### 2.4 `lines[]` 台詞

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | ✔ | 句子代號（英數、`_`、`-`），專案內不可重複，**改台詞時不要改 id**。建議 `001`、`case2-07` 這種格式 |
| `role` | ✔ | 角色 `id` |
| `text` | ✔ | 畫面上顯示的台詞（也是預設要唸的文字） |
| `say` |  | 實際要唸的文字（和 `text` 不同時才填）。用在：數字改中文（`20.1萬`→`二十點一萬`）、多音字改同音字、刪掉括號註解 |
| `instruct` |  | 這一句的情緒／語氣，用簡短中文，例如「痛得哭出來，聲音發抖」「壓低聲音，狡猾地慫恿」 |
| `key` |  | 程式播放時用的查詢鍵。不填時依 `output.keyFormat` 產生（預設 `{role}\|{text}`） |
| `note` |  | 備註（App 會顯示，不影響語音） |

**每一句真正送進模型的內容：**
- 文字＝`say`（沒有就用 `text`），再套用 `pronunciation`
- 指令＝`instruct`（全域）＋ `roles[].instruct` ＋ `lines[].instruct`，以「；」相接
- 音色＝`roles[].speaker`

**寫台詞與指令的建議**
- 一句不要超過 80 個字；太長請拆成兩句（兩個 id）。
- 不要放 `<laugh>` `[笑]` 這類標記，模型會照唸。笑、嘆氣、倒抽一口氣請寫在 `instruct`（例如「一開始帶著笑聲」）。
- 不要用「嘿嘿、嘻嘻、哈哈」這類語氣詞來表達情緒，唸起來很假；寫在 `instruct`。
- 數字、英文縮寫、符號請在 `say` 寫成要唸的樣子：`119`→`一一九`、`3:00`→`三點`、`km`→`公里`。
- 指令只寫**情緒與語氣**，用短句：「很害怕，聲音發抖」比「害怕」好；同一種情緒盡量用同一句話描述。不要寫「用低沉的聲音」「尖聲」這類改變音色的話。

### 2.5 讀音：`pronunciation[]` 與注音標記

模型主要用大陸的簡體中文訓練，直接給繁體字或台灣讀音容易唸錯。App 送進模型前會自動做三件事（電腦端編輯器也會即時顯示「送進模型」的文字）：

1. **注音 → 字**：標了注音的字詞，換成「大陸讀音剛好是這個音」的常用字（只有一種讀音的字優先）。原本的字如果模型本來就這樣唸，就保留不換。
2. **台灣讀音**（`engine.taiwan`，預設開）：台灣與大陸讀音不同的常用詞，自動換成台灣讀音，例如星期 ㄒㄧㄥ ㄑㄧˊ、垃圾 ㄌㄜˋ ㄙㄜˋ、學姊 ㄐㄧㄝˇ、危險 ㄨㄟˊ、拚命 ㄆㄢˋ。詞表約 1,300 條，取自新酷音詞庫中台灣最常用的讀法，並和教育部辭典核對過。
3. **轉成簡體字**：其他文字全部轉簡體（OpenCC），例如籃→篮、腳→脚、開著→开着。

畫面上的字幕不受影響。

**標注音的兩種寫法**

```json
"pronunciation": [
  { "from": "縫", "zhuyin": "ㄈㄥˊ" },
  { "from": "操場", "zhuyin": "ㄘㄠ ㄔㄤˇ" },
  { "from": "一行人", "to": "一航人" }
]
```

```json
{ "id": "011", "role": "nar", "text": "送到醫院縫了好幾針。", "say": "送到醫院縫{ㄈㄥˊ}了好幾針。" }
```

- `{ "from", "zhuyin" }`：專案裡所有句子的這個字詞都照這個注音唸（建議用這種）。注音用空白隔開每個字；輕聲寫 `˙ㄓㄜ` 或 `ㄓㄜ˙` 都可以。
- 句子裡的 `字{注音}`：只改這一句；大括號前面有幾個注音音節，就套用到前面幾個字（`垃圾{ㄌㄜˋ ㄙㄜˋ}`）。
- `{ "from", "to" }`：直接換成別的字（舊寫法，仍然支援）。
- 優先順序：注音標記 > 台灣讀音詞表 > 轉簡體。台灣讀音詞表的某個詞不想用時，用注音標記蓋過去，或把 `engine.taiwan` 設成 `false`。
- 多音字（長、重、還、行、教、轉…）不會自動改，App 和編輯器會標「⚠ 多音字」提醒你聽一下。
- 手機上也可以在每一句按「🔤 讀音」新增修正（存在手機上，和專案檔的修正一起使用）。

### 2.6 `output` 輸出設定

| 欄位 | 預設 | 說明 |
|---|---|---|
| `type` | `"game-voice-v1"` | 輸出格式，見第 3 節 |
| `sampleRate` | `24000` | 固定 24000 |
| `mp3Kbps` | `64` | MP3 位元率（32–160） |
| `leadSec` | `0.5` | 音檔開頭的空白秒數 |
| `gapSec` | `0.4` | 句子之間的空白秒數 |
| `keyFormat` | `"{role}\|{text}"` | `key` 的預設格式，可用 `{role}` `{text}` `{id}` |

### 2.7 語音長度與乾淨度（App 自動處理）

為了讓語音和字幕同步、沒有多餘的聲音，App 對每一句做：

1. **去掉多餘聲音**：句子前後的喘氣、雜音、空白全部去掉；句子中間的喘氣換成安靜，停頓最長 0.3 秒（台詞有「……」的句子最長 0.5 秒）。
2. **長度檢查**：正常語速約每字 0.18–0.3 秒。長度明顯不對（多了奇怪的聲音、漏字、拖太長）會自動重錄，最多 3 次；還是不對就標成「可能有問題」讓人挑版本。
3. **只保留寫在台詞裡的聲音**：笑聲、哭聲、狀聲詞要的話，請直接寫進 `text` 或 `say`（例如「哈哈哈！」「嗚嗚……」「哼！」），模型才會唸出來；不要靠指令讓模型自己加。

`map.txt` 裡的長度就是處理後的語音長度（含回聲、殘響的尾音）。

### 2.8 在 App 裡覆蓋的設定

使用者可以在手機上替每個角色換 `speaker`、調整 `post`（存在手機上，覆蓋專案檔）。之後再匯入新版專案檔時，手機上的覆蓋設定會保留；按「恢復專案檔的設定」可以取消。換音色的角色，句子會標成「已修改」，按「一鍵完成」就會重錄。

## 3. 輸出格式 game-voice-v1（程式要讀的檔案）

App 匯出兩個檔案（存在手機的 `Download/語音工作室/<專案id>/`，也可以直接分享）：

| 檔案 | 內容 |
|---|---|
| `all.txt` | 全部句子接成**一個 MP3**（24 kHz 單聲道），再轉成 **base64 文字**（GitHub Pages、各種主機都能放） |
| `map.txt` | JSON：`{ "<key>": [開始秒數, 長度秒數, "嘴型數字串"], ... }` |

- 嘴型數字串：每 40 ms 一個數字（25 fps），`0`＝閉嘴、`9`＝張最大。
- 只會包含已經錄好的句子；沒錄的句子不會出現在 `map.txt`，程式要自己改用裝置朗讀或略過。
- 檔案放在程式的 `voice/` 資料夾：`voice/all.txt`、`voice/map.txt`。

### 3.1 程式播放範例（瀏覽器）

```js
const VO = { map: {}, el: null };
async function loadVoice() {
  VO.map = JSON.parse(await (await fetch('voice/map.txt')).text());
  const b64 = (await (await fetch('voice/all.txt')).text()).trim();
  const bin = atob(b64), u = new Uint8Array(bin.length);
  for (let i = 0; i < bin.length; i++) u[i] = bin.charCodeAt(i);
  VO.el = new Audio(URL.createObjectURL(new Blob([u], { type: 'audio/mpeg' })));
}
// key 例如 'xiaokai|快點過來！我們要去操場搶籃球場！'
function playLine(key, onMouth) {
  const m = VO.map[key]; if (!m) return false;            // 沒有語音 → 改用 speechSynthesis
  const [start, dur, lips] = m, el = VO.el;
  el.currentTime = Math.max(0, start - 0.04); el.play();
  const tick = () => {
    const t = el.currentTime - start;
    if (t >= dur || el.paused) { el.pause(); onMouth && onMouth(0); return; }
    const i = Math.floor(t * 25); onMouth && onMouth(i >= 0 && i < lips.length ? +lips[i] / 9 : 0);
    requestAnimationFrame(tick);
  };
  requestAnimationFrame(tick); return true;
}
```

- **字幕同步**：有語音的句子，字幕的打字速度用語音長度決定：每秒字數 = 字數 ÷（長度 × 0.92），讓最後一個字在語音結束前出現；「下一步」在語音播完（長度＋0.15 秒）後才能按。沒有語音的句子才用固定速度。
  ```js
  const m = VO.map[key];                                   // [start, dur, lips]
  const cps = m ? Math.min(30, Math.max(2.5, text.length / (m[1] * 0.92))) : 13;
  const minMs = m ? m[1] * 1000 + 150 : Math.max(1500, text.length * 115);
  ```
- 手機瀏覽器第一次播放前需要使用者點擊（解鎖音訊）。
- 建議程式也提供「匯入語音」按鈕：讓使用者在手機上直接選 `all.txt` 和 `map.txt`，存在 IndexedDB，不用重新上傳網站（`校園安全時光機` 的 `index.html` 有完整範例：`VDB`、`importVoiceFiles`、`loadVoice`）。

## 5. 驗證清單（產生專案檔的程式請自行檢查）

1. `format`、`version`、`id`、`title`、`roles`、`lines` 都存在；`id` 符合 `^[a-z0-9][a-z0-9-]{1,63}$`。
2. 角色 `id` 不重複；每個 `speaker` 在 9 個音色內。
3. 句子 `id` 不重複；每句的 `role` 都找得到角色。
4. `text` 不是空的、不超過 300 字；`say`／`text` 裡沒有 `<…>` 或 `[…]` 標記（`{注音}` 可以）；注音都看得懂。
5. 產生的 `key` 不重複（重複的台詞請用不同的 `key`，或保證兩句內容完全相同時只需錄一次）。
6. `post` 數值在範圍內；角色的 `instruct` 沒有描述音色（高低、粗細、年齡）。
7. 想要的笑聲、哭聲、狀聲詞已經寫在台詞文字裡，指令裡沒有「加上喘氣聲」之類會產生多餘聲音的要求。
8. 播放語音的程式用 `map.txt` 的長度控制字幕速度（見 §3.1）。

可以用 `docs/voiceproj.schema.json`（JSON Schema 2020-12）做格式驗證，或用 `pc/語音專案編輯器.html` 開啟檔案，它會列出所有錯誤。
