🎙 語音工作室

第一步：下載模型

這個 App 用 Qwen3-TTS 模型在手機上離線產生語音。模型約 2 GB，只要下載一次，建議連 Wi-Fi。

語音專案

或貼上專案檔的網址（例如 GitHub 上的檔案連結）：
專案檔在電腦上產生（遊戲程式或「語音專案編輯器」），用 LINE、雲端硬碟或 USB 傳到手機，再按上面的「匯入」。 同一個專案再次匯入時，只有改過的句子需要重錄。

換了音色或想讓全部句子用新設定重錄時使用
匯出檔案：手機的「Download/語音工作室//」裡的 all.txt 和 map.txt，放進遊戲的 voice/ 資料夾或用遊戲的「匯入語音」。
後製：每個角色固定一個音色，再用後製做出角色感：男童、女童、可愛女聲、渾厚男聲、一般女聲、一般男聲、惡魔、天使，或打開「細項調整」自己調。 「音高統一」會把每一句拉到同樣的音高，讓同一個角色聽起來一致。在這裡調整會覆蓋專案檔的設定，不用重錄、不用網路。

語音模型

下載很慢或失敗時，可以填鏡像網站（例如 https://hf-mirror.com），或先用電腦下載模型檔（.gguf）再傳到手機，按「從手機檔案匯入」。
